# legal-pages

Public landing pages and privacy policies for our browser extensions, served by GitHub Pages.

| Extension | Landing page | Privacy policy |
| --- | --- | --- |
| Gleaner – Bulk Image Downloader | [`bulk-downloader/`](bulk-downloader/) | [`bulk-downloader/privacy.html`](bulk-downloader/privacy.html) |

Live at `https://vali-pnt.github.io/legal-pages/<extension>/` once Pages is on (Settings → Pages → Deploy from a branch → `main` / root).

One folder per extension. Shared styles are in `assets/site.css`. Only user-facing pages belong in this repo: it is public.
